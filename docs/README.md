## 7. 规矩（防止再滚出第八版）

1. **现行文档文件名不带版本号**，版本只写在文件头表格里。文件名一旦带 v2/v3，就会有人以为还有 v4 的另一个文件。
2. **旧版不删除、只归档**：移到 `docs/archive/`，文件头加三行——
   ```
   > **[已废止 v3.0]** 请勿参考。
   > 替代文档：`数据库开发书/v4.0_数据库重塑设计.md`
   > 废止日期：2026-11-11
   ```
3. **一处改动、一处回写**：改数据库设计 → 同时检查 `api_contract`、`frontend.md`、`upgrade_checklist`，以及本 README 第 2 节。
4. **新增文档先在本 README 登记**，登记不进去的，说明它不该存在。
5. **副本只留一处**：`数据库开发书` 三个副本合并成一个，且必须在 git 里。
6. 归档命名：`archive/原文件名_20261111_v3.0.md`，保留原文件名便于搜索。
