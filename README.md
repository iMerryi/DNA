# DNA医疗档案系统 (DNA Medical Archive System)

基于DNA序列编码的医疗数据加密桌面系统 —— 将医疗健康档案编码为DNA序列存储，实现**安全加密**与**长期冷归档**。

> 1克DNA可存储约215PB数据，保质期理论上可达数百年。

---

## 项目概述

| 属性 | 内容 |
|------|------|
| **项目名称** | DNA医疗档案系统 |
| **当前版本** | v1.0 |
| **开发模式** | 4人协作（PM/核心算法 + 前端 + 数据库 + AI） |
| **技术栈** | Python 3.8+ / Flet / C++17 / SQLite / Ollama(Qwen2.5) |

### 核心能力

- **加密流程**：医疗文档 → AI智能提取 → 数据分类 → 密钥生成 → **DNA序列编码**
- **解密流程**：DNA序列输入 → 密钥验证 → **DNA解码还原** → 智能纠错 → 档案导出
- **隐私保障**：全部数据本地存储，AI本地部署，数据不出本机

---

## 功能特性

### 加密（数据写入）

- 多源数据输入：手动填写表单 / 导入文档(txt/docx/pdf) / 上传图片(预留OCR)
- AI智能字段提取：自动识别33个目标字段，结构化输出
- 数据预处理：字段分类(物理/反复/病症) → 拼音转换 → 病症标准化
- DNA核心编码：文本→二进制→XOR加密→DNA碱基映射→生物特性优化(GC含量/热稳定性)

### 解密（数据读取）

- 多源DNA输入：手动粘贴 / 导入文件 / 数据库选择
- DNA完整解码：序列校验→移除人工碱基→二进制还原→XOR解密→文本输出
- 智能纠错：相似度检索 + AI推理，修复解码错误
- 结果导出：JSON / DOCX 格式，含完整性报告

### 界面与交互

- Flet桌面GUI，支持Windows 10/11
- 游客一键进入（无需注册登录）
- 侧边任务栏，支持多任务并行(≥3个)
- 实时进度条 + 友好错误提示

## 快速开始

### 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / Windows 11 |
| Python | >= 3.8 |
| 内存 | >= 4GB RAM |
| 分辨率 | >= 1280 x 720 |

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动Ollama服务

```bash
# 安装Ollama（如未安装）
# 下载地址: https://ollama.com

# 拉取AI模型
ollama pull qwen2.5:7b-instruct

# 可选：拉取纠错用的大模型
ollama pull qwen2.5:14b-instruct

# 启动Ollama服务
ollama serve
```

### 编译C++编解码器

```bash
cd DNA_code/
# 使用Visual Studio或MinGW编译DNA_encoder.cpp和DNA_decoder.cpp
# 编译后生成 .exe 文件放到 DNA_code/DNA_code/ 目录下
```

### 运行程序

```bash
python main.py
```

## 编码映射规范

> 本节定义DNA编码过程中二进制到DNA碱基的映射规则及生物特性约束标准。
> 详细内容待核心算法模块完成后补充。

### 二进制 → DNA碱基映射

| 二进制 | DNA碱基 | 说明 |
|--------|---------|------|
| 11 | A | - |
| 01 | T | - |
| 10 | C | - |
| 00 | G | - |

### DNA碱基 → 二进制映射（反向）

| DNA碱基 | 二进制 | 说明 |
|---------|--------|------|
| A | 11 | - |
| T | 01 | - |
| C | 10 | - |
| G | 00 | - |

### 人工碱基标记

| 标记 | 含义 | 使用场景 |
|------|------|---------|
| X | 人工填充碱基 | GC含量不足时插入 |
| Y | 人工填充碱基 | 与X配对使用 |

### 生物特性约束

#### GC含量约束

| 参数 | 目标值 | 允许范围 | 说明 |
|------|--------|---------|------|
| GC含量 | 50% | 40% ~ 60% | G和C所占比例 |

#### 热稳定性系数

| 碱基 | 稳定性系数 | 说明 |
|------|-----------|------|
| A | 1.0 | 腺嘌呤 |
| T | 1.0 | 胸腺嘧啶 |
| C | 1.5 | 胞嘧啶 |
| G | 1.5 | 鸟嘌呤 |
| X | 1.8 | 人工碱基 |
| Y | 1.8 | 人工碱基 |

#### 自适应修复策略

| 场景 | 处理方式 | 待补充 |
|------|---------|--------|
| GC含量过低 | 插入CG片段 | - |
| GC含量过高 | 插入AT片段 | - |
| 序列长度不对齐 | 填充X/Y标记 | - |
| 其他约束冲突 | - | - |

### XOR加密规格

| 参数 | 规格 |
|------|------|
| 加密算法 | XOR异或 |
| 密钥长度 | 16字符（十六进制） |
| 密钥生成 | SHA-256(姓名+出生日期) 取前16位 |
| 密钥存储 | 仅存哈希，不存明文 |

## 字段定义

### 物理存储字段（23个）

| 分类 | 字段列表 |
|------|---------|
| 基本信息 | 档案编号、姓名、性别、出生日期、证件号码 |
| 地址联系 | 户籍地址、常住地址、建档机构、建档日期、联系电话 |
| 体征信息 | 民族、ABO血型、Rh血型 |
| 家庭信息 | 父亲姓名、父亲电话、母亲姓名、母亲电话 |
| 出生情况 | 出生孕周、出生体重、出生身长、分娩机构、Apgar(1min)、Apgar(5min) |

### 病症记录字段（7个）

苯丙酮尿症、先天性甲状腺功能减低症、听力筛查、过敏史、先天异常、既往住院史、家族遗传病史

### 反复存储字段（3个）

随访日期、当前体重、体温（支持多条记录）

## 安全机制

| 安全项 | 实现方式 |
|--------|---------|
| 数据加密 | XOR异或 + DNA碱基映射 |
| 密钥保护 | 仅存储SHA-256哈希，不存明文 |
| 数据隔离 | 本地SQLite，不上云 |
| AI隐私 | Ollama本地部署，数据不出本机 |
| 临时文件 | 程序退出时自动清理 |
| 删除安全 | 软删除机制，不物理删除数据 |
